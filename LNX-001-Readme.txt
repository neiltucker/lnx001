## ILT or Bootcamp Delivery
This 1-day course teaches students foundational Linux administration on modern Ubuntu systems.
Students learn core command-line operations, local user and group administration, storage and
filesystem management, network configuration, OpenSSH security, and host defense with UFW.

The course supports both standard Instructor-Led Training (ILT) and intensive Bootcamp delivery
with an afternoon Capstone Lab: "Edge Sensor Station Provisioning and Security Hardening".

For additional help in configuring standard or customized deliveries, please contact us at:
support@softwaretutorialservices.com

## Lab Environment:
Students use a local machine, VM, or WSL2 environment running Ubuntu 24.04 LTS with sudo/root access.
The automated lab setup script `LNX-001-Setup.ps1` is included in this repository to automate
local directory preparation, accounts, and prerequisite checks.
